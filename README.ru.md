# ppa-add

**[Read in English](README.md)**

`ppa-add` служит альтернативой `add-apt-repository` при добавлении и удалении
[Launchpad PPA](https://launchpad.net/) в Ubuntu и её деривативах.

## Зачем ppa-add?

Если вы когда-нибудь сталкивались с тем, что стандартный рецепт вида
`sudo add-apt-repository ppa:someuser/somerepo` не работает, — этот скрипт
для вас. Мы с моим другом
[М. Вибе](https://github.com/mistralai/mistral-vibe) написали его
на чистом Bash.

Что не так со стандартным инструментом? Понятия не имею. Но:

- Ключ PPA получается через `dirmngr`, который может нагружать процессор
  на 100%, а потом просто завершится с ошибкой.
- О том, что какого-то ключа не хватает, можно узнать слишком поздно —
  из вывода `apt update`.

`ppa-add` вместо этого:

1. Одним запросом получает страницу PPA и читает из неё отпечаток ключа
   подписи и список релизов (Launchpad API — запасной источник для обоих).
2. Проверяет выбранный релиз по фактически существующим `InRelease`-файлам
   PPA — до того, как что-либо записано в систему.
3. Скачивает ключ по HTTPS и сверяет отпечаток скачанного ключа с
   отпечатком, опубликованным на Launchpad — ошибочный или подменённый
   ключ не будет установлен.
4. Пишет deb822-файл `.sources` с `Signed-By:`, закрепляя ключ в
   `/etc/apt/keyrings/`, так что ключ доверен только этому PPA — а не всем
   репозиториям системы.

## Требования

- Ubuntu или дериватив (Linux Mint и т.п.) с apt
- bash 4+, `curl`, `gpg`, `sudo`

## Установка

```bash
sudo install -Dm755 bin/ppa-add /usr/local/bin/ppa-add
```

Установка необязательна: `bash bin/ppa-add …` прямо из каталога проекта
тоже работает.

## Использование

```
ppa-add [-r] [-n] <user/repo> [suite]

  -r, --remove     отключить PPA (sources-файл и ключ подписи)
  -n, --no-update  не запускать apt-get update в конце
```

`suite` по умолчанию — кодовое имя системы; оно разрешается по цепочке
`DEBIAN_CODENAME` → `UBUNTU_CODENAME` → `VERSION_CODENAME` (из
`/etc/os-release`), поэтому работает и на Ubuntu, и на деривативах, чьё
собственное кодовое имя не совпадает с убунтовской серией (Linux Mint).

```bash
# Добавить PPA для кодового имени текущей системы
sudo ppa-add someuser/somerepo

# Добавить PPA для конкретной серии
sudo ppa-add someuser/somerepo jammy

# Добавить несколько PPA, обновить индекс один раз
sudo ppa-add -n user1/repo1
sudo ppa-add -n user2/repo2
sudo apt-get update

# Удалить PPA: его sources-файл(ы) и ключ
# (установленные пакеты остаются; для отката версий сначала ppa-purge)
sudo ppa-add -r someuser/somerepo
```

Если в PPA нет релиза для запрошенной серии, утилита перечислит доступные
и ничего не запишет:

```
ppa-add: no release 'noble'. Available: jammy focal
     (ppa-add someuser/somerepo <one of them>)
```

## Коды выхода

- `0` — успех
- `1` — сетевая ошибка или ошибка валидации (ничего не записано)
- `2` — ошибка использования (неизвестная опция или неверные аргументы)
